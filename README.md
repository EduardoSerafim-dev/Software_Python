# Software_Python 🐍

Software em Python que possui módulos que podem ser acessados pelo usuário, cada módulo apresenta diversas funcionalidades.

### Módulo 1 – Matemática:  🔢

O módulo Matemática possui funcionalidades relacionadas a operações matemáticas diversas.

### Módulo 2 – Texto: ✍️

O módulo Texto possui funcionalidades relacionadas à manipulação de textos.

### Módulo 3 – Escola: 🏫

O módulo Escola possui operações diversas relacionadas à vida escolar de um estudante. 

### Módulo 4 – Miscelâneas: 💡
O módulo Miscelâneas possui operações diversas não categorizadas.
